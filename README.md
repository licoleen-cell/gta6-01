Solvado Heat — an open-world crime game on the Palm Coast, built for make.fun's gta6-01 bounty.
Explore the city of Solvado on foot and by car, steal cars, dodge traffic and pedestrians,
raise your wanted level, outrun the police, and run four chained story missions.

## Run it

Open `game/index.html` in desktop Chrome (no network, no build step), or serve it:

```sh
node serve.ts
```

Then open http://localhost:8080. Controls: WASD/arrows to move, Shift to run, E to enter/exit a car,
J to punch, M to mute. Save/load via localStorage.

Build the entry dossier (what the grader runs):

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```
